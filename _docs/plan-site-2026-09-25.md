# Plan du site isomorph.dev (HELM, 2026-09-25)

Contenu : uniquement `_docs/inventaire-contenu-2026-09-25.md`. Aucun ajout. Aucun nom de client public.
Système de design : Console (`src/components/console`), choix retenus des journaux isomorph.fr (fond Crêtes, liens Tension, notifications et pages d'erreur Journal, Saira pour le texte).
Langues : FR par défaut, EN conservé (next-intl existant), traduction fidèle du FR.

## Arborescence

| Route | Contenu | Source |
|---|---|---|
| `/` | Hero (Hero Console, puis expériences 3D en option), quatre entrées : Plugins, Code, Expérimentations, Veille ; derniers éléments de chaque rubrique | inventaire §1 à §4 |
| `/plugins` | Liste : Link, Cookie Consent, Comments (Strapi) ; Point relais, ISOMORPH SEO (Shopify, statut « pilote » et « en développement », sans client nommé, sans lien vers dépôt privé) | §1 |
| `/plugins/[slug]` | Fiche : rôle, statut, version, compatibilité, liens npm et GitHub publics. Comments garde tarifs et bouton de paiement existants (mécanique inchangée) | §1, `data.ts` |
| `/code` | Paquets et dépôts publics (npm `@isomorph-agency/*`, `strapi-plugin-cookie-consent(-v4)`, GitHub public) avec commande d'installation et bloc de code | §2 (public seulement) |
| `/experimentations` | Galerie des démonstrations (heros 3D, Terminal, globe, carte, décors, fonds) ; chaque démonstration jouable sur sa page, chargée à l'approche | §3 |
| `/experimentations/[slug]` | Démonstration en plein écran, fiche courte (technologie, ce que ça montre) | §3 |
| `/veille` | Éditions de veille technique publiées, sans mention interne (ni agents, ni skills, ni clients) | §4.1, §4.2 |
| `/atelier` | Système de design complet, `noindex` | port Console |
| `/mentions-legales`, `/confidentialite`, `/cgv` | Textes LEGAL (`_docs/legal/`) | LEGAL |
| `/checkout/success`, `/admin/licenses` | Mécanique existante, habillage Console | existant |

Anciennes routes : `/about` et `/plugins/strapi-comments` redirigées (301) vers leur équivalent.
